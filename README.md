# AI Fake News Detection

## Description
This project detects whether a news article is Fake or Real using NLP and Machine Learning.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- NLP
- TF-IDF Vectorizer

## Model Used
Passive Aggressive Classifier

## Accuracy
Approximately 94% - 97%

## Dataset
Fake.csv
True.csv

## Run
python fake_news.py
